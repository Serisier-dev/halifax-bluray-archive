# Halifax Blu-ray Archive

A searchable static archive of Blu-ray titles observed in the Halifax Public Libraries catalogue, ordered by catalogue acquisition order.

**Live source:** [Halifax Public Libraries Blu-ray search](https://halifax.bibliocommons.com/v2/search?query=blu-ray&searchType=smart)

## Current snapshot

- Archive titles: 759
- Last checked against the live catalogue: August 6, 2026
- The archive preserves historical entries. Its count may exceed the current live catalogue when older records are withdrawn.
- New records include direct links to their exact Halifax BiblioCommons pages.

## Use

Open `index.html`, or use the GitHub Pages site. Everything required for browsing, searching, filtering, sorting, and exporting is embedded in the single HTML file.

## Updating

Search the Halifax catalogue for `blu-ray`, retain the default **Date acquired** order, and add records from the top until reaching a title already present in `DATA`. Preserve older archived records rather than deleting withdrawn titles.

Film metadata is embedded for offline browsing. Catalogue publication years and record links come from Halifax Public Libraries; descriptive film metadata should be verified from public references before adding it.
